# Calm AI

## From Prediction to Prevention

Calm AI is a web prototype designed to support people who experience panic attacks.

The idea is to use AI concepts and health data analysis to help users understand their symptoms, recognize possible triggers, and get support during difficult moments.

## Problem

Panic attacks can happen suddenly and may cause:

* Fast heartbeat
* Difficulty breathing
* Dizziness
* Fear and stress

During these moments, many people cannot easily ask for help or use their phones.

## Solution

Calm AI provides a simple support system that helps users:

* Monitor their condition
* Understand possible triggers
* Use calming techniques
* Receive guidance during panic moments

## Main Features

* Panic Risk Analysis
* Emergency Mode
* Breathing Exercises
* Grounding Technique
* AI Recommendations
* User Dashboard

## Technologies

This prototype is built using:

* HTML
* CSS
* JavaScript

## Future Development

Future versions may include:

* Machine Learning Model
* Smart Watch Integration
* Mobile Application
* Doctor and Family Dashboards

## Project Goal

The goal of Calm AI is to make panic attack support easier and help users feel safer in their daily lives.
